# Employee Registration System

An ASP.NET Core Blazor web application for managing employee records.

## Features

- Register employees
- View employee records
- Search employees
- Edit employee information
- Delete employees
- Form validation
- SQL Server database integration

## Technologies

- C#
- ASP.NET Core
- Blazor Server
- Entity Framework Core
- SQL Server
- Bootstrap

## Project Requirements

The system manages employee information including:

- Civil ID
- File Number
- Full Name
- Department
- Job Title
- Email
- Mobile Number
- Employment Date
- Registration Date
